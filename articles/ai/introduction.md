# Introduction

Build and publish websites, platforms, games, and native apps by asking Claude.

---

## What is Manifest?

Manifest builds and hosts websites, web apps, platforms, and games for you, through Claude, and can package them as native apps for the App Store, Google Play, and desktop. Describe what you want, and Claude builds it, shows you a preview, and publishes it to a web address anyone can open. Later, ask for changes the same way.

You don't need to write code, set up a server, or learn hosting. You add Manifest to Claude once, then ask.

> `Build a landing page for our new product, with pricing and a signup form`{copy}
> `Turn this spreadsheet into a searchable product catalog`{copy}
> `Build a client portal where customers sign in and track their orders`{copy}
> `Make a quiz game about our product for the trade show`{copy}
> `Turn this project into an iPhone and Android app`{copy}

---

## How it works

1. **Add the Manifest [plugin](/docs/ai/setup/claude-plugin) to Claude** and sign in. You do this once, on any Claude plan.
2. **Ask Claude to build something**, or open a project you already have. The [Quickstart](/docs/ai/setup/quickstart) walks you through it.
3. **Ask Claude to publish it.** You get an address like `acme-launch.manifestx.ai`, and you can switch to your own domain whenever you like.

---

## New projects and existing ones

**New projects** are built with Manifest's open-source [framework](/docs/framework), which is designed for AI to write. Claude uses Manifest's skills to lay out pages, style them, add forms and data, translate them, and make them easy to find in search.

**Existing projects** built with something else, such as React, Vite, Astro, or plain HTML, can keep their own setup (or ask Claude to duplicate them with the Manifest framework for [SEO/AEO](/docs/framework/publishing/seo-aeo) optimization and other benefits). Regardless, the Manifest plugin can publish and host any project.

::: brand icon="lucide:info"
Manifest hosts projects that run in the browser, and native apps are packaged from the same project. Manifest doesn't run server code: accounts and saved data come from a connected service such as Appwrite, and Claude helps you set it up.
:::

## What you can do

- **Publish** to a web address, and **preview changes** on a separate staging address first.
- **Use your own domain**, with the security certificate handled for you.
- **Undo** a change by going back to an earlier version.
- **Work as a team**, each person from their own Claude chats.
- **View analytics**, like how many users came, which pages they visited, and where from.
- **Keep track of everything** in the Manifest [dashboard](/docs/ai/projects/manage).

## Words you'll see

| Word | Meaning |
|---|---|
| Project | One website, app, platform, or game. |
| Preview | Your project running on your own computer, visible only to you. |
| Staging | A separate copy at its own web address, for checking changes before they go live. |
| Live | The version everyone sees. Also called *production*. |
| Plugin | The add-on that lets Claude use Manifest. |
| Domain | A web address you own, like `example.com`. |
