# Claude

Build, publish, and run your sites from Claude.

---

## Two ways to add Manifest

You can add Manifest to Claude as a **connector** or a **plugin**. Both sign in to the same Manifest account and give Claude the same abilities. The plugin adds extra know-how for building sites.

| | Connector | Plugin |
|---|---|---|
| Works in | Claude on the web, desktop, and phone, and Claude Code | Claude Code |
| Adds | Manifest's tools | Manifest's tools, plus skills and commands for building sites |
| Best for | Managing sites that are already online | Building, editing, and publishing sites |

**Which should you choose?** If you use Claude Code, install the [plugin](/docs/ai/setup/plugin). It already includes the connector. Otherwise, add the [connector](/docs/ai/setup/connector).

---

## What you can do where

Building and publishing a site means working with files on your computer, so you do that in Claude Code. Once a site is online, you can manage it from any Claude app.

| Task | Claude on the web, desktop, or phone | Claude Code |
|---|---|---|
| Build or edit a site | | ✓ |
| Publish a site | | ✓ |
| Take a staged version live | ✓ | ✓ |
| Go back to an earlier version | ✓ | ✓ |
| Connect your own domain | ✓ | ✓ |
| Invite people | ✓ | ✓ |
| See your visitors | ✓ | ✓ |

---

## What is Claude Code?

Claude Code is a version of Claude that can work with files on your computer. You can use it in the **Code** tab of the Claude desktop app, or in a terminal. To build and preview sites, your computer also needs <a href="https://nodejs.org" target="_blank">Node.js</a>, a free tool that Claude uses to run your site.
