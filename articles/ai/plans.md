# Plans

What's free, and what Pro adds.

---

## Free and Pro

Everything you need to build and publish is free. Pro adds history, teams, and control over Manifest's branding. Each project has its own plan, so you only pay for the projects that need Pro.

| | Free | Pro |
|---|---|---|
| Build, preview, and publish with Claude | ✓ | ✓ |
| A `.manifestx.ai` web address | ✓ | ✓ |
| Your own domains, with security certificates | ✓ | ✓ |
| Staging, to check changes before they go live | ✓ | ✓ |
| Visitor analytics | Last 7 days | All time |
| Undo changes and download past versions | | Last 5 versions |
| Invite teammates and make admins | | ✓ |
| "Made with Manifest" badge | Shown | Removed |
| Manifest's showcase | May be featured | Your choice |

---

## What Pro adds

- **All-time analytics.** Keep your full visitor history, not just the last week.
- **Undo and download.** Go back to any of your last 5 versions of staging or live, or download one as a backup.
- **Teams.** Invite people to work on the project from their own Claude, as members who can edit and publish, or admins who can also invite others.
- **No badge.** The small "Made with Manifest" badge is removed from every page.
- **Showcase control.** Keep the project out of Manifest's public gallery of projects. This doesn't affect search engines either way.

---

## Upgrade

Only a project's owner can upgrade it. Ask Claude, and it gives you a secure checkout link that shows the price before you pay. The project switches to Pro within seconds.

> `Upgrade this project to Pro`{copy}

---

## Manage billing

Ask Claude for a link where you can change or cancel the plan, update your payment method, and download invoices.

> `Manage my billing`{copy}

If a payment fails or you cancel, Pro features keep working for 14 days. Then the project moves to Free and stays online.
