The Manifest API

Publishing, built into your product. Straight from your code.

Create, update, and publish Manifest projects from your own systems, whether for your own content or for your customers. Manifest handles hosting, staging, domains, and history.

POST /v1/projects

{ "source_id": "store_8231", "name": "Acme Store" }

PATCH /v1/projects/proj_7Hc2/files

{ "files": [{ "path": "index.html", "content": "…" }] }

POST /v1/projects/proj_7Hc2/promote

shop.acme.com is live

How it works

  1. 1

    Create a project

    Make a project for anything you want to publish, tagged with your own ID so you can find it again.

    Projects
  2. 2

    Send updates

    Upload a full build, or change just the files you need. Every update lands on staging first.

    Editing
  3. 3

    Go live

    Promote what you checked on staging to the live address, and add a custom domain if you like.
