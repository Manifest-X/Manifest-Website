Common questions

Something else? Contact the team.

What counts as a project?

One site or app with its own address and versions. Plans are per project, so teammates never cost extra; inviting them comes with Pro.

Should I use Claude chat or the Code tab?

Both publish to Manifest. A chat suits small sites: Claude sends the files with the conversation, which keeps projects to 10 MB (2 MB per file), and it works on Claude's Free plan. The Code tab, on paid Claude plans, keeps the project in a folder on your computer with no size limit, so it's the better start for apps and anything you'll keep working on.

How does Claude know a project uses Manifest?

Once Manifest is added to Claude, ask for it by name, like "build me a site with Manifest." In the Code tab, the project folder includes a CLAUDE.md file that tells every new session it's a Manifest project, so open the same folder to pick up where you left off. The folder works with Git like any code project, and GitHub is optional: handy for teams, never needed to publish.

Can I publish a site I already have?

Yes, if it builds to static files, like a React, Vite, Astro, or plain HTML site. Claude publishes the build as it is, without moving it to Manifest. Sites that need a server of their own, such as server-side rendering or API routes, aren't hosted; the published site can call a backend that runs elsewhere.

Who owns what I build?

You do. Any project can download its last 5 published versions on any plan. The framework is open source under the MIT License and runs anywhere, and the API publishes from your own code, so Claude is optional.

What is the badge?

Free sites show a small "Made with Manifest" link, and Free projects may be featured in the showcase on manifestx.dev. Pro removes the badge and lets you choose whether the project is featured.

How does billing work?

Per project through Stripe, monthly or yearly. Upgrade or cancel from the dashboard, or just ask Claude. If you cancel, your site stays live: Pro runs to the end of the paid period, then the project moves to Free, the badge returns, and form submissions older than 30 days are removed.
