What it is

A bridge between AI editors and your framework.

Manifest AI isn't a chatbot. It doesn't replace Claude, ChatGPT, or whatever AI you already use. It's a Model Context Protocol (MCP) server — a standardized way for AI tools to fetch project-specific knowledge.

Connect your editor to the Manifest AI MCP server and it gains the same understanding of the framework that a senior Manifest developer has: every directive, every component pattern, every data-source shape, every prerender behavior. The same AI you already trust now generates correct Manifest code.

Quick clarifications
  • Not a new AI. Use your existing Claude / ChatGPT / Cursor / Windsurf subscription. Manifest AI just makes them framework-aware.
  • Not a code generator. Your AI still does the generating. Manifest AI supplies the framework grammar so it gets the answer right.
  • Not a build dependency. Install once, use everywhere. Doesn't change your project's runtime, deployment, or output.

Install

Two minutes to install. Zero ongoing setup.

Manifest AI runs as an MCP server. Add it to your editor's MCP configuration and it stays available across every project, every conversation.

Add to your ~/.claude.json or run the install command:

npx mnfst-ai install --editor=claude-code
Restart Claude Code and the Manifest AI tools will appear in the tool list.

Add to your Cursor settings (Settings → MCP Servers) or run:

npx mnfst-ai install --editor=cursor
Reload Cursor's MCP servers from settings to activate.

Add to ~/.codeium/windsurf/mcp_config.json or run:

npx mnfst-ai install --editor=windsurf
Restart Windsurf to load the new MCP server.

Manifest AI works with any MCP-compatible client. Use this server URL in your client's MCP configuration:

{
              "mcpServers": {
              "manifest-ai": {
              "command": "npx",
              "args": ["-y", "mnfst-ai"]
              }
              }
              }
Compatible clients include Claude Desktop, Continue, Zed, and any editor implementing the Model Context Protocol.

FAQ

Questions about Manifest AI.

Does Manifest AI replace Claude or ChatGPT?

No. Manifest AI is an integration, not an AI. You keep using your existing Claude / ChatGPT / Cursor / Windsurf subscription. Manifest AI just teaches those tools the Manifest framework so they generate correct code.

What is the Model Context Protocol (MCP)?

MCP is an open protocol introduced by Anthropic in 2024 that lets AI tools fetch external context (documentation, project files, API access) on demand. Manifest AI runs as an MCP server, so any MCP-compatible editor can use it. You don't need to know how MCP works to use Manifest AI — the install command handles all of it.

Does it send my code to a server?

The community tier runs entirely locally — Manifest AI knowledge is bundled with the MCP server and queried in-process. Your code never leaves your machine. Pro tier uses an optional cloud component for team workspaces and premium components, but you choose what gets shared.

Can I cancel anytime?

Yes. Pro is month-to-month, no contract. Cancel any time and you retain access through the end of your billing period, then drop back to the free Community tier with no data loss.

Does it work offline?

The MCP server runs locally and answers your AI's queries without network access. The only thing that requires connectivity is whatever your AI editor itself needs (Claude, Cursor, etc.) — Manifest AI doesn't add a new network dependency.

Is it open source?

The Manifest framework itself is MIT-licensed. The Community-tier MCP server is also open. Pro-tier components and the team-workspace infrastructure are proprietary — that's what funds ongoing development of the open-source framework.
