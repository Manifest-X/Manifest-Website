Install

Two minutes. One command.

npx mnfst-ai install --editor=claude-code
npx mnfst-ai install --editor=cursor
npx mnfst-ai install --editor=windsurf

Manifest AI works with any MCP-compatible client. Add to your config:

{
              "mcpServers": {
              "manifest-ai": {
              "command": "npx",
              "args": ["-y", "mnfst-ai"]
              }
              }
              }

FAQ

Quick questions.

Is this a new AI?

No. You keep using Claude, ChatGPT, Cursor, or whichever AI you already pay for. Manifest AI just makes those tools fluent in Manifest.

Does it send my code anywhere?

Community tier runs entirely locally — your code never leaves your machine. Pro tier uses optional cloud features for team workspaces; you choose what gets shared.

Can I cancel anytime?

Yes. Pro is month-to-month. Cancel and you keep access through the end of the billing period, then drop back to Community with no data loss.

Is it open source?

The Manifest framework is MIT-licensed. The Community-tier integration is open. Pro-tier components and team infrastructure are proprietary — that's what funds the open-source framework.

What's MCP?

Model Context Protocol — an open standard that lets AI tools fetch external context on demand. Manifest AI runs as an MCP server, so any MCP-compatible editor can use it. You don't need to know how it works to use it.
