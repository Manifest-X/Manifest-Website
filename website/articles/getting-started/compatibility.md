# Compatibility
Designed to work in all major browsers.

---

## Frameworks

The latest version of Manifest is designed to be used with:
- Alpine JS v3 and above
- Tailwind CSS v4 and above

Depending on scope, Manifest's modular scripts and stylesheets can be dropped into projects running on other frameworks, e.g. just to apply icons, color modes, or theme styles.

---

## Browsers

The latest version of Manifest is designed for and tested on the current stable versions of Chrome, Firefox, Edge, and Safari.

Manifest only uses native language features that have been declared web-standard, but note that older browser versions—or divergent browsers like Firefox—may lack support for more modern HTML and CSS capabilities, such as HTML's `popover` attribute for menus and tooltips. Polyfill scripts can be used to mimic support for these abilities in older browsers.

Check <a href="https://caniuse.com" target="_blank">Can I Use?</a> for specific browser feature support.
